# Akku.GG store preview

A clickable preview of the Akku.GG online store, published with GitHub Pages:
**https://kunyonepal.github.io/akkugg/**

This repository only holds the built preview pages (sample products, prices and draft policy text).
Orders placed in the preview stay in the visitor's browser and are not sent anywhere.
The store's source code, server and admin panel are not in this repository.
